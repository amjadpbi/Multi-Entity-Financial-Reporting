# Multi-Entity Financial Reporting

This repository contains a multi-entity financial reporting practice model built around local Excel and CSV source files stored in `data/source`.

## Scope
The project demonstrates a Power BI model for comparing actual and budget performance across multiple entities and time periods. The source files include entity-specific financial statements and mapping files used to normalize the data before reporting.

## Evidence in this repository
- `Multi_Entity Power BI Report.pbip`
- `Multi_Entity Power BI Report.pbix`
- `data/source/` for the imported source workbooks and CSV extracts
- `docs/PROJECT_AUDIT.md` for the supporting technical evidence summary

## Notes
- This project uses local practice/demo data and is not presented as a production financial deployment.
- The `Power BI` project artifacts remain in place and were not altered.
- Report and model references were preserved while the source files were organized into the `data/source` folder.
